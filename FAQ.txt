PuzzleProof Studio FAQ

Installation

Q: How do I install PuzzleProof Studio on Windows?
A: Unzip PuzzleProofStudio-v0.1.0-Windows.zip, open the PuzzleProofStudio folder, and double-click PuzzleProofStudio.exe. You do not need to install Python and you do not need to use PowerShell.

Q: What should I do if Windows SmartScreen appears?
A: During Early Access, the app may be unsigned. Choose More Info, then Run Anyway only if the ZIP came directly from BayouFinds / Wonder Piece Studio.

Licensing

Q: How do I activate a license?
A: Place your private license file named license.json in the licenses folder next to PuzzleProofStudio.exe, then close and reopen the app.

Q: Where does license.json go?
A: Put it here after extracting the ZIP:

PuzzleProofStudio\licenses\license.json

Q: What happens if I do not have a license file yet?
A: During Early Access, the app can use the included sample license so testing is not blocked.

Projects

Q: How do I create a project?
A: Open the Project tab, enter the artist name, artwork title, contact details, copyright owner, approval status, and project notes. Click Save Project before exporting artwork or generating print files.

Q: Where are project records saved?
A: Project JSON files are saved in the jobs folder. Catalog metadata is saved in catalog\catalog.json.

Artwork

Q: How do I import artwork?
A: Open the Image Conversion tab, choose the source artwork file, select the export target, then run the export action.

Q: My artwork import or export failed. What should I check?
A: Confirm the source image still exists, the file is a supported image format, and the app has permission to write into the exports folder.

Printing

Q: How do I generate print files?
A: Save the project, then open the Printing tab and choose the document or production package you need. Generated HTML files are saved in the exports folder.

Q: Does PuzzleProof Studio print directly to my printer?
A: The current workflow creates print-ready files for review. Native printer selection is not part of this Early Access build.

Catalog

Q: How do I find a saved project?
A: Use the Catalog tab to search by artist name, artwork title, or catalog ID. Use Show All to reset filters.

Support

Q: How do I find support links?
A: Open Help > FAQ for support links, Help > Contact Support to start an email, Help > Report Issue for the issue tracker, or Help > Product Website for the product page.

Q: Where are logs saved?
A: Logs are saved in the logs folder next to PuzzleProofStudio.exe. Use Help > Open Logs Folder to open that folder.

Q: What should I do if the app will not launch?
A: Re-extract the ZIP into a normal folder such as Documents, confirm PuzzleProofStudio.exe is still inside the PuzzleProofStudio folder, and try again. If it still will not launch, send the latest file from the logs folder plus your Windows version to support.

Q: How do I contact support?
A: Use Help > Contact Support, copy the Support tab information, and include the steps that led to the problem.
