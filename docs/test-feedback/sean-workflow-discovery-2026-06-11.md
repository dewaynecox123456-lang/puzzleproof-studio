## Current Workflow
Customer image is received through Facebook Messenger, Discord, TikTok Messages, text message, or email. Image is transferred to the production computer, then imported into Microsoft Word as Sean's current manual workaround. The real pain point is repeatedly resizing, cropping, and positioning the image for three outputs:

1. Puzzle image
2. Box insert image
3. Box label / sticker image

## Time Impact
Current setup time is approximately 10–20 minutes per order.

Desired setup time is approximately 1–3 minutes per order.

## Product Direction
PuzzleProof Studio should prioritize:

- One customer image import
- Automatic generation of Puzzle Print, Box Insert, and Box Sticker / Label layouts
- DOCX export for transition comfort during the move away from Word-based manual setup
- PNG or JPG export for direct print-ready image workflows
- Preview before print
- Clear output folders

Batch processing and social media package generation are future considerations and are not part of this focused preset output workflow.
