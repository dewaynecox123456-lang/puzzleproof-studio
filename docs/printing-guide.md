# PuzzleProof Studio Printing Guide

PuzzleProof Studio creates print-ready files. It does not send jobs directly to a printer yet. After creating a file, review the saved output and print it from Word, LibreOffice, a browser, or your preferred PDF/DOCX viewer.

## Output Location

Printing files are saved in the app's `exports` folder. The Printing tab shows the exact folder path and the most recent file created.

## Document Types

### Artist Release

Use this for artist permission and project approval records. Review the artist name, artwork title, copyright owner, approval status, and signature area before printing.

Suggested output: standard letter paper.

Suggested printer: standard inkjet or laser printer.

### Copyright Form

Use this to record ownership and reproduction permission details for the artwork.

Suggested output: standard letter paper.

Suggested printer: standard inkjet or laser printer.

### Production Sheet

Use this as the internal production record for catalog number, artwork details, approval status, source artwork, and export notes.

Suggested output: standard letter paper.

Suggested printer: standard inkjet or laser printer.

### Sticker

Use this for package label copy or small sticker review sheets.

Suggested output: sticker paper or label stock.

Suggested printer: inkjet, laser, or label printer matched to the paper type.

### Insert

Use this for customer insert content, artist attribution, and package notes.

Suggested output: standard paper, light cardstock, or insert stock.

Suggested printer: standard inkjet or laser printer.

### Puzzle Cover

Use this as a front cover reference sheet for proofing, packaging, and production review.

Suggested output: photo paper, presentation paper, or cardstock depending on the final use.

Suggested printer: photo printer, inkjet printer, or production printer.

### Production Package

Use this to create the full set of print-ready production documents at once.

Suggested output: mixed paper types based on the individual documents above.

Suggested printer: choose the printer and paper type separately for each file.

## Printer Selection

Printer selection happens outside PuzzleProof Studio for now. Open the generated file, review it, then choose the printer, paper size, paper type, scaling, and number of copies in Word, LibreOffice, a browser, or your preferred PDF/DOCX viewer.

Before printing, confirm:

- The catalog number and artwork title are correct.
- The approval status is correct.
- The copyright owner is correct.
- The output file is the document type you intended to create.
- The selected printer and paper match the document type.
