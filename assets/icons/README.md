# PuzzleProof Studio Icons

Placeholder icon set for Build 2 cleanup.

- `puzzleproof-icon.svg` is the color source concept: deep green background, antique gold accent, puzzle piece, and artist palette.
- `puzzleproof-icon.xbm` is a lightweight monochrome Linux window icon used by Tkinter.
- A Windows `.ico` should be generated from the SVG before release packaging and referenced in PyInstaller with `--icon assets\icons\puzzleproof-icon.ico`.

These are placeholders for Sean testing and can be replaced by final Wonder Piece Studio artwork later.
