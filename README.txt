PuzzleProof Studio
Version 0.1.3-SeanValidation

PuzzleProof Studio is a desktop utility for the BayouFinds / Wonder Piece Studio artist-to-puzzle workflow. It helps track artwork approvals, project records, image exports, catalog metadata, and print-ready production documents.

support@bayoufinds.com

Basic Workflow:
1. Open the Project tab and enter artist, artwork, approval, copyright, and catalog details.
2. Save the project.
3. Import artwork in the Image Conversion tab and export production assets.
4. Review saved records in the Catalog tab.
5. Use the Printing tab to generate releases, production sheets, inserts, stickers, covers, and production packages.
6. Use Help > FAQ for built-in troubleshooting and support links.
